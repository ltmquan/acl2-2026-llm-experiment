This page runs a JavaScript port of the model in 04-binmonjil-chandy-lamport/exp1/solution.lisp (the experiment-1 solution). Functions and fields use the ACL2 names. The abstract application and topology (the encapsulate) are given the same concrete functions as the reviewer's evaluation script reviews/04-binmonjil-chandy-lamport-exp1-eval.lsp.

3. Space–time diagram and the recording cut

One lane per process. Each dot is an input, in execution order. Arrows are messages from the input that sent them to the input that received them; dashed purple arrows are markers. The red line is the cut: on each lane it passes just after rp. In e the cut zig-zags, and postrecording inputs (orange) can come before prerecording ones (blue). In (append pre post) the same inputs are re-ordered so the cut is one vertical line.

4. Why pre and post steps commute

Sort e by repeatedly swapping an adjacent pair x; y where x is postrecording and y is prerecording (an "inversion"). Each swap is checked by actually running both orders: from the state S before the pair, (cl-run S (list x y)) and (cl-run S (list y x)) must be equal. If they are, the rest of the run is unchanged, so the final state is unchanged. When no inversions remain, the sequence is (append pre post).

About this page

The model code is a direct port of exp1/solution.lisp (records g/s, local-ps, local-out, head-of, pop-chans, deliver, cl-step, legal-input, recorded-p, segment-target, checkpoint-complete, complete-segment-p, pre-inputs, post-inputs, state-equiv). It was checked against ACL2 8.7 running the certified solution, with the same concrete functions attached via defattach: on 41 executions (the example and 40 random legal ones), the final state, pre-inputs, post-inputs, complete-segment-p and state-equiv of the reordering all matched. The commuting checks on this page are computed, not assumed. The general proof is reorder-from-state and MAIN in the solution. The message arrows in section 3 are bookkeeping for the picture only and are not part of the model's state.

⏺ Adjoining a root of an irreducible monic polynomial

  This is an explanation only; I didn't run anything new. I'll break the
  sentence into its parts, then put it back together. The examples are the same
  ones I tested against the solution earlier.

  ---

  Step 0: What is a field?

  A field is a set of "numbers" where you can add, subtract, multiply, and
  divide by anything except 0, and the usual algebra rules hold (commutativity,
  distributivity, and so on). Those rules are the "field axioms" in the theorem.

  ┌─────────────────────────────┬────────┬──────────────────────────────────┐
  │             Set             │ Field? │               Why                │
  ├─────────────────────────────┼────────┼──────────────────────────────────┤
  │ Q (fractions)               │ ✅     │ 3/4 ÷ 2/5 is still a fraction    │
  ├─────────────────────────────┼────────┼──────────────────────────────────┤
  │ Integers Z                  │ ❌     │ 1 ÷ 2 is not an integer          │
  ├─────────────────────────────┼────────┼──────────────────────────────────┤
  │ F₂ = {0, 1}, arithmetic mod │ ✅     │ 1 + 1 = 0, and 1⁻¹ = 1           │
  │  2                          │        │                                  │
  ├─────────────────────────────┼────────┼──────────────────────────────────┤
  │ F₅ = {0,1,2,3,4}, mod 5     │ ✅     │ for example 2·3 = 6 ≡ 1, so 2⁻¹  │
  │                             │        │ = 3                              │
  ├─────────────────────────────┼────────┼──────────────────────────────────┤
  │ Z₆ = {0,…,5}, mod 6         │ ❌     │ 2·3 = 0, so 2 has no inverse     │
  └─────────────────────────────┴────────┴──────────────────────────────────┘

  Integers mod n form a field exactly when n is prime. That's why the paper says
  "the integers modulo a prime."

  ---

  Step 1: A polynomial over f

  A polynomial over f is an expression like

  p(x) = c₀ + c₁x + c₂x² + … + cₙxⁿ      where every cᵢ comes from f

  Here x is just a symbol, not a number. The degree is the highest power with a
  nonzero coefficient.

  The solution stores a polynomial as a list of coefficients, constant term
  first:

  x² − 2      →  (-2 0 1)
  x² + x + 1  →  (1 1 1)

  ---

  Step 2: Monic

  Monic means the leading coefficient is 1:

  x² − 2      monic ✅
  3x² − 6     not monic ❌   (divide by 3 to get x² − 2)

  Requiring monic polynomials is a convenience. Over a field you can always
  divide by the leading coefficient, so every polynomial has a monic version
  with the same roots.

  ---

  Step 3: Root, and why we might need to adjoin one

  A root of p is a value r with p(r) = 0.

  The key observation is that a polynomial over f may have no root inside f:

  x² − 2  over Q:   the root would be √2, but √2 is not a fraction
  x² + 1  over R:   the root would be i, but no real number squares to −1
  x² + x + 1  over F₂:  try both elements
                        x=0:  0+0+1 = 1 ≠ 0
                        x=1:  1+1+1 = 3 ≡ 1 ≠ 0     → no root in F₂

  Adjoining a root means building a bigger field that contains f plus a new
  element (call it α) with p(α) = 0.

     ┌─────────────────────────────┐
     │  bigger field  f(α)         │
     │    ┌───────────┐            │
     │    │  f        │   α  ←── new element with p(α) = 0
     │    └───────────┘            │
     │   plus everything you can   │
     │   build from f and α with   │
     │   +, −, ×, ÷                │
     └─────────────────────────────┘

  You've already seen this once: the complex numbers are the reals with a root
  of x² + 1 adjoined. That root is called i.

  ---

  Step 4: What do the elements look like?

  Take Q with a root α of x² − 2 adjoined, so α is √2. Expressions in α can
  collapse, because α² − 2 = 0 lets you rewrite α² as 2:

  α³ = α · α² = α · 2 = 2α
  α⁴ = (α²)² = 4

  Any power of α of degree 2 or higher shrinks back down. So every element can
  be written as

  a + bα        with a, b in Q

  In general, if p has degree n, every element is a polynomial in α of degree 
  less than n. This is exactly the paper's wording: "the elements of such an
  extension are the polynomials over f of degree less than that of p."

  Q(√2):  elements a + b·√2      (degree < 2)   solution stores  (a b)

  ---

  Step 5: Arithmetic means polynomial arithmetic, reduced mod p

  - Addition combines like terms, and nothing overflows: (1 + 2α) + (3 − α) = 4
    + α.
  - Multiplication multiplies as polynomials, then reduces mod p. You divide by
    p and keep the remainder, which is the same as repeatedly replacing α² with
    2:

  (1 + α)(3 + α) = 3 + 4α + α²
                 = 3 + 4α + 2        ← replace α² by 2
                 = 5 + 4α

  This is what "polynomial addition and multiplication modulo p" means. It's
  just like clock arithmetic (mod 12), but with polynomials instead of numbers.

  The earlier tests checked exactly this:

  √2 · √2 = α² → 2                     solution gave (2 0)   ✅
  x³ + 5 mod (x² − 2) = 2x + 5         solution gave (5 2)   ✅

  ---

  Step 6: Why must p be irreducible?

  Irreducible means p can't be factored into smaller pieces over f. The paper's
  precise version: p has no non-constant monic divisor of lower degree.

  Here's what goes wrong with a reducible p. Take x² − 1 = (x − 1)(x + 1) over
  Q. Mod this p,

  (α − 1)(α + 1) = α² − 1 = 0

  Two nonzero things multiply to 0. Then α − 1 can't have an inverse: if it had
  one, multiplying both sides by it would force α + 1 = 0, which is false.
  Division fails, so the result is not a field. It's the same problem Z₆ had in
  Step 0, where 2·3 = 0.

  reducible p   →  zero divisors  →  some elements have no inverse  →  not a 
  field ❌
  irreducible p →  every nonzero element has an inverse              →  field ✅

  This is the polynomial version of "n must be prime." It's also why the
  theorem's highlighted claim (x · x⁻¹ = 1) is the hard part. Irreducibility is
  exactly what makes inverses exist.

  Inverse example in Q(√2):

  1/(1 + √2) = (−1 + √2)
  check: (1 + √2)(−1 + √2) = −1 + √2 − √2 + 2 = 1  ✅
  solution gave (-1 1)  ✅

  ---

  Step 7: Why "degree at least 2"?

  A degree-1 monic polynomial looks like x − c, whose root c is already in f.
  Adjoining it adds nothing new, so the paper excludes it.

  ---

  Worked example with a finite field: F₂ to F₄

  Use base field F₂ = {0, 1} and p = x² + x + 1. Step 3 showed it has no root in
  F₂. It's also irreducible: a factorization would need a degree-1 factor,
  which would give a root.

  Adjoin α with α² + α + 1 = 0. In F₂, minus equals plus, so the rewrite rule is
  α² = α + 1.

  The elements are all polynomials of degree < 2 with coefficients 0 or 1.
  That's 2 × 2 = 4 elements:

  0,   1,   α,   1+α           ← a brand-new field with 4 elements: F₄

  Here is the multiplication table, using α² = α + 1:

     ×   │  0     1     α     1+α
    ─────┼─────────────────────────
     0   │  0     0     0     0
     1   │  0     1     α     1+α
     α   │  0     α    1+α    1        ← α·(1+α) = α + α² = α + α + 1 = 1
    1+α  │  0    1+α    1     α

  Every nonzero row contains a 1, so every nonzero element has an inverse. It's
  a field. (The solution computed α·(1+α) → (1 0), meaning 1.)

  Putting the sentence back together

  ▎ "A simple extension of a field f is constructed by the usual process of 
  ▎ adjoining a root of an irreducible monic polynomial p over f [of degree ≥ 
  ▎ 2]."

   start with field f
          │
          ▼
   pick p: coefficients in f, leading coeff 1, degree ≥ 2, can't be factored
          │
          ▼
   invent α with p(α) = 0      (α is not in f)
          │
          ▼

               add normally, multiply then reduce mod p
          │
          ▼
   irreducibility ⇒ every nonzero element has an inverse ⇒ it's a field

  "Simple" means you adjoin one root. "Recursively" (from the next sentence in
  the paper) means you can repeat the process on the result. For example, Q →
  Q(√2) → Q(√2)(√3). That's why fieldp in the solution is recursive: an (:ext f 
  p) is a field when f is a field and p is monic, irreducible over f, and of

❯ Can you help me build an intuition around polynomial division? How does it    
  work?                                                                         

⏺ Polynomial division

  Short version: polynomial division works like the long division you learned in
  school. Each step asks "how many times does the divisor go in?" and
  subtracts, until what's left is too small to divide.

  ---

  Step 1: Start with integers

  Divide 137 by 12:

  137 = 12 × 11 + 5
            ↑      ↑
       quotient  remainder (smaller than 12, so we stop)

  The rule is:

  dividend = divisor × quotient + remainder,    with remainder < divisor

  Polynomial division keeps the same rule, but measures "size" by degree:

  a(x) = q(x) × Q(x) + r(x),    with deg r < deg q

  ---

  Step 2: The core move is to kill the leading term

  Each step does one thing: match the leading term of what's left, subtract, and
  repeat.

  Divide a = x³ + 2x² + 5 by q = x² − 2 over Q.

  Round 1. What times x² gives x³? Answer: x.

    x³ + 2x² + 0x + 5
  − x · (x² − 2)   =   x³ − 2x
    ─────────────────────────
           2x² + 2x + 5          ← the x³ term is gone

  Round 2. What times x² gives 2x²? Answer: 2.

    2x² + 2x + 5
  − 2 · (x² − 2)   =   2x² − 4
    ─────────────────────────
           2x + 9                ← degree 1 < degree 2, so stop

  Result:

  x³ + 2x² + 5  =  (x² − 2)(x + 2)  +  (2x + 9)
                             ↑           ↑
                         quotient    remainder

  Check by expanding: (x² − 2)(x + 2) = x³ + 2x² − 2x − 4. Adding 2x + 9 gives
  x³ + 2x² + 5. ✅

  Each round lowers the degree by at least one, so the process always finishes.

  ---

  Step 3: The same thing in a picture

  Think of the coefficients as a row of columns. Each round removes the leftmost
  one:

  degree:     3    2    1    0
  a:        [ 1    2    0    5 ]
  −x·q:     [ 1    0   −2    0 ]      q = x²−2 shifted up one place
            ────────────────────
                 [ 2    2    5 ]
  −2·q:          [ 2    0   −4 ]
                 ───────────────
                      [ 2    9 ]      ← remainder 2x + 9

  It's just subtracting shifted copies of the divisor.

  ---

  Step 4: Why "monic" makes this easy

  At each step you divide the leading coefficient of what's left by the leading
  coefficient of q. If q is monic (leading coefficient 1), that division is
  trivial: the multiplier is just the leading coefficient itself.

  If q is not monic, say 3x² − 6, you need to divide by 3. That requires a 
  field, where every nonzero number has an inverse. Over the integers, x² ÷ 2x
  would need 1/2, which doesn't exist, so the division gets stuck. That's one
  more reason the whole theory is set "over a field."

  ---

  Step 5: "Mod p" means the remainder

  "Reduce mod p" just means divide by p and keep the remainder, the same way 137
  mod 12 = 5.

  From the example above:

  x³ + 2x² + 5   mod (x² − 2)   =   2x + 9

  This connects to the shortcut from last time. Each subtraction of a multiple
  of (x² − 2) is the same as replacing x² with 2:

  x³ + 2x² + 5
  = x·x² + 2·x² + 5
  = x·2  + 2·2  + 5      ← x² → 2
  = 2x + 9               ✅ same answer

  So "adjoin α with α² = 2" and "do arithmetic mod x² − 2" are the same 
  operation, described two ways.

  ┌───────────────────────────┬──────────────────────────────┐
  │         Integers          │         Polynomials          │
  ├───────────────────────────┼──────────────────────────────┤
  │ 137 mod 12 = 5            │ (x³+2x²+5) mod (x²−2) = 2x+9 │
  ├───────────────────────────┼──────────────────────────────┤
  │ Remainder < 12            │ Remainder has degree < 2     │
  ├───────────────────────────┼──────────────────────────────┤
  │ Possible remainders: 0…11 │ Possible remainders: a + bx  │
  ├───────────────────────────┼──────────────────────────────┤
  │ Z mod prime → field       │ f[x] mod irreducible → field │
  └───────────────────────────┴──────────────────────────────┘

  That last row is the core idea behind the construction in the paper.

  ---

  Step 6: Divisibility

  q divides a means the remainder is zero, exactly as with integers (12 divides
  144 because 144 mod 12 = 0).

  Over F₂ (where 1 + 1 = 0, so subtracting equals adding), divide x² + 1 by x + 
  1:

    x² + 0x + 1
  − x·(x + 1)  =  x² + x
    ──────────
         x + 1             (in F₂, 0 − x = x)
  − 1·(x + 1)
    ──────────
           0               ← remainder 0, so x+1 divides x²+1

  Indeed (x + 1)² = x² + 2x + 1 = x² + 1 in F₂.

  Now try x² + x + 1:

    x² + x + 1
  − x·(x + 1)  =  x² + x
    ──────────
             1             ← remainder 1 ≠ 0, so it doesn't divide

  These are the tests I ran on the solution earlier: pdivides returned T for the
  first and NIL for the second.

  This is what "reducible" means in the definition: some smaller monic q leaves
  remainder 0.

  ---

  Step 7: Remainders and roots

  Dividing by a degree-1 polynomial (x − c) gives a useful fact:

  a(x) = (x − c)·Q(x) + r      (r is a constant, since its degree is < 1)

  Plug in x = c and the first term vanishes, so r = a(c).

  Consequences:
  - Dividing by x − c is the same as evaluating at c.
  - c is a root ⟺ (x − c) divides a.

  That's why, for degree 2 or 3, "no roots in f" means "irreducible": any
  factorization would need a degree-1 factor, which would give a root. (From
  degree 4 up this breaks down. A polynomial can have no roots and still split
  into two quadratics.)

  ---

  Step 8: How the solution computes it

  The solution's pmod doesn't do textbook long division. It uses Horner's 
  scheme, which builds the polynomial from the top coefficient down and reduces
  as it goes:

  x³ + 2x² + 0x + 5  =  ((1·x + 2)·x + 0)·x + 5

  Start with 1. Then, repeatedly, multiply by x, reduce mod p right away
  (vtimesx), and add the next coefficient. Since the running value is reduced at
  every step, it never grows past degree < deg p. The final result is the same
  remainder.

  It's like computing 137 mod 12 digit by digit: 1 → 13 mod 12 = 1 → 17 mod 12 =
  5. That's a different route to the same answer, and the concrete tests agreed
  with hand calculation.

  ---

  Step 9: Where division leads (inverses)

  Here's why irreducibility gives inverses. Repeated division (the Euclidean 
  algorithm) finds the greatest common divisor of two polynomials. If p is
  irreducible and u is nonzero mod p, their only common divisors are constants.
  The algorithm then produces s and t with

  s·u + t·p = 1

  Reduce that mod p and the t·p term disappears, leaving s·u ≡ 1. So s is the
  inverse of u.

  The solution's inv-search is a version of this. It keeps dividing p by smaller
  remainders until it reaches a nonzero constant, and keeps track of the
  multiplier as it goes. The comment at solution.lisp:384 describes this
  invariant.

  ---

  Summary

  division  = repeatedly subtract shifted copies of the divisor
              until the degree is too small
  mod p     = the leftover part, also "replace α^n using p(α)=0"
  divides   = leftover is zero
  root at c = (x − c) divides
  inverse   = run division repeatedly (Euclid) to reach 1

  If it helps, I can work a short Euclidean-algorithm example step by step, for
  example the inverse of 1 + √2 in Q(√2) from last time.

❯ Is a polynomial quotient unique? Are there certain conditions that need to be 
  met such that the polynomial and remained produced by division are unique?    

⏺ Is the quotient unique?

  Yes, if you require the remainder to have smaller degree than the divisor, and
  the divisor's leading coefficient can be divided by. Over a field, the second
  condition holds for any nonzero divisor. If either condition is dropped,
  uniqueness or existence can fail.

  ---

  The theorem

  ▎ Let f be a field, and let a and q be polynomials over f with q ≠ 0. Then 
  ▎ there is exactly one pair (Q, r) with
  ▎ a = q·Q + r     and     r = 0 or deg r < deg q

  Everything in the statement matters:

  ┌──────────────────────────────────┬──────────────────────────────────────┐
  │            Condition             │        What breaks without it        │
  ├──────────────────────────────────┼──────────────────────────────────────┤
  │ q ≠ 0                            │ You can't divide by zero, just as    │
  │                                  │ with integers.                       │
  ├──────────────────────────────────┼──────────────────────────────────────┤
  │ deg r < deg q                    │ Uniqueness fails (see Condition 1).  │
  ├──────────────────────────────────┼──────────────────────────────────────┤
  │ Coefficients from a field, or at │ Existence can fail, and with "zero   │
  │  least q's leading coefficient   │ divisors" uniqueness fails too       │
  │ invertible                       │ (Conditions 2 and 3).                │
  └──────────────────────────────────┴──────────────────────────────────────┘

  ---

  Why it's unique: the proof

  Suppose there were two answers:

  a = q·Q₁ + r₁
  a = q·Q₂ + r₂

  Subtract one from the other:

  q·(Q₁ − Q₂)  =  r₂ − r₁

  Compare degrees:

  Right side:  r₁ and r₂ both have degree < deg q
               so  deg(r₂ − r₁) < deg q

  Left side:   if Q₁ ≠ Q₂, then Q₁ − Q₂ is a nonzero polynomial, and
               deg(q·(Q₁ − Q₂)) = deg q + deg(Q₁ − Q₂)  ≥  deg q

  A polynomial can't have degree both below deg q and at least deg q. So Q₁ = 
  Q₂, and then r₁ = r₂ as well.

                    degree
       ≥ deg q ┃ ████ q·(Q₁−Q₂)   ← must live up here if Q₁ ≠ Q₂
      ─────────╂──────────────── deg q
       < deg q ┃ ████ r₂ − r₁     ← must live down here

  The key step is "deg(q · something nonzero) ≥ deg q." It says multiplying by q
  can't make the degree drop. All the conditions above exist to keep that step
  valid.

  ---

  Condition 1: Without "deg r < deg q", it's not unique

  If any remainder is allowed, you can always move a piece of the quotient into
  the remainder:

  x² + 1  =  x · x       + 1           (Q = x,     r = 1)
  x² + 1  =  (x − 1) · x + (x + 1)     (Q = x − 1, r = x + 1)
  x² + 1  =  0 · x       + (x² + 1)    (Q = 0,     r = x² + 1)

  All three equations are true. The degree rule is what makes the remainder the
  remainder, the same way 137 = 12·11 + 5 = 12·10 + 17 for integers, where only
  5 counts because 5 < 12.

  ---

  Condition 2: Without a field, existence can fail

  Over the integers Z, divide x by 2x:

  x = 2x · Q + r      with deg r < 1, so r is a constant

  The x-coefficients force 2·(coefficient of Q) = 1, so Q would need to be 1/2,
  which isn't an integer. No valid answer exists.

  The fix: if q's leading coefficient is invertible (1 always is, so monic q
  works), division works over any commutative ring. That's another reason the
  paper's polynomials are monic. Over a field, every nonzero leading coefficient
  is invertible, so any nonzero q works.

  ---

  Condition 3: With "zero divisors", uniqueness can fail

  The proof used deg(q·S) = deg q + deg S. That depends on (nonzero) × (nonzero)
  ≠ 0 for the leading coefficients. Some number systems don't have this
  property.

  Take integers mod 4, where 2·2 = 4 ≡ 0. Let q = 2x + 1, whose leading
  coefficient is 2 (not invertible mod 4):

  (2x + 1)·(2x + 1) = 4x² + 4x + 1 ≡ 1   (mod 4)

  Multiplying q by a degree-1 polynomial gave degree 0, so the degree went down.
  Now divide a = 1 by q:

  1 = (2x + 1)·0        + 1      Q = 0,      r = 1   (deg 0 < 1 ✓)
  1 = (2x + 1)·(2x + 1) + 0      Q = 2x + 1, r = 0   ✓

  There are two valid answers, so uniqueness fails.

  Fields have no zero divisors, and a monic q has leading coefficient 1, so the
  paper's setting has neither problem.

  ---

  Summary of conditions

                           existence    uniqueness
   over a field, q ≠ 0         ✅           ✅
   any ring, q monic           ✅           ✅      ← leading coeff 1 is 
  invertible
   over Z, q = 2x              ❌ (x ÷ 2x)   ✅      ← no zero divisors
   over Z/4, q = 2x + 1        —            ❌      ← 2·2 = 0
   no degree rule on r         ✅           ❌

  ---

  Why this matters for the field construction

  Uniqueness is what makes "a mod p" a well-defined thing. Each polynomial has
  exactly one remainder of degree < deg p. That's why the extension field can
  say "the elements are the polynomials of degree less than deg p":

  - every polynomial reduces to one representative, and
  - two representatives are equal as field elements only if they're the same
    polynomial.

  Without uniqueness, a single field element could have two "names," and
  checking equality would be ambiguous.

  The solution reflects this in solution.lisp. Each extension element is a
  coefficient list of length exactly deg p (vecp), so there's exactly one
  representation per remainder. pmod and pquot compute this unique remainder and
  quotient.

  ---

  A caveat: formal polynomials vs functions

  Uniqueness is about polynomials as formal expressions (lists of coefficients),
  not as functions. Over F₂, x² and x give the same output for both inputs (0²
  = 0, 1² = 1), but they're different polynomials. Dividing either one by (x² +
  x + 1) gives a different remainder. The paper and the solution both treat
  polynomials as formal coefficient lists, which is the right choice here.
